# ChemSetu

Bridging Science and Synthesis. Official web platform for ChemSetu Lifesciences Private Limited, specializing in API impurities, pharmaceutical intermediates, and custom chemical synthesis.

## Features

- Modern interactive user interface built with React 19
- 3D interactive molecule visualization with Three.js
- Dynamic catalog and search for API impurities & chemical compounds
- Complete responsive design and optimized mobile navigation
- Built-in SEO metadata, schema.org structured data, and open graph tags

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm start
```

### Production Build

```bash
npm run build
```
